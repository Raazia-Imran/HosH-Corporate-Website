# HosH Corporate Website

A motion-rich corporate website for industrial inspection, certification, technical assurance, and training.

## Current direction

- **Theme:** Midnight Intelligence
- **Visual language:** midnight black, deep navy, cyan glow, technical interfaces
- **Motion references:** RSI Studio's cinematic quality and Iconics-style continuous energy
- **Engineering goal:** modular, reusable, secure, accessible, and fully responsive

## Quick start

```bash
git clone https://github.com/Raazia-Imran/HosH-Corporate-Website.git
cd HosH-Corporate-Website
npm install
npm run dev
```

Open http://localhost:3000.

## Validation

```bash
npm run lint
npm run build
```
